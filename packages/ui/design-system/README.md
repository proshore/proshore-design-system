Proshore products use one calm, accessible system: neutral surfaces, one accent (Proshore blue), pill-shaped actions, Geist type, and status that always travels with an icon and a word. This system is a generated mirror of `@proshore/ui` {{version}} (generated by `npm run export:design-system`); the code is the source of truth.

## Content fundamentals
- Sentence case. Plain language first, technical detail on demand. Buttons are verbs that say what happens: "Confirm mapping", not "OK".
- Status is never colour alone: pair `pr-observed-*`, `pr-inferred-*`, `pr-confirmed-*` and `pr-danger-*` with an icon and a label. Observed (from a scan), inferred (unconfirmed) and confirmed (reviewed) are different claims; do not use confirmed styling for unreviewed data.

## Visual foundations
- **Color.** Canvas `pr-canvas`, cards `pr-surface`, quiet fills `pr-surface-muted`, hairlines `pr-line`. Text: `gray-12` primary, `gray-11` secondary. One accent: `accent-9` for the solid action, `pr-accent-text` for links. The Proshore orange lives in the logo mark.
- **Themes.** Light and Dark both ship and both must pass checks. Dark is standard dark grey (canvas `{{dark:pr-canvas}}`, cards `{{dark:pr-surface}}`, primary text `{{dark:gray-12}}`), not black and not navy. Do not add a third theme.
- **Type.** Geist (`--font-sans`) for text, Geist Mono (`--font-mono`) for code and eyebrows. Body is `text-3` (1rem); nothing smaller than 12px (`text-1`).
- **Spacing and radius.** Space steps `space-1` to `space-9` (4 to 64px). Cards use `pr-radius-card` ({{light:pr-radius-card}}), tags `radius-1` ({{light:radius-1}}), buttons and nav `radius-full` (pills).
- **Elevation.** Light uses the soft `pr-card-shadow`; dark uses a 1px inset hairline from the same token.
- **Focus and targets.** 2px focus ring in `focus-8` with 2px offset; every interactive element at least 24 by 24px; keyboard operable.
- **Motion.** Subtle, and off with `prefers-reduced-motion`.

## Iconography and logos
- Product icons are Radix 15px icons, thin line, `currentColor`. Do not add another icon library. See `assets/Logos/README.md` for the marks.

## Components
Previews are static markup rendered from the real `@proshore/ui` components with the real stylesheet (`components/bundle.css`). The live library is React 19 with React Aria; it is not run inside this system. Build with the package (`import "@proshore/ui/styles.css"`) and the project skill (`npx proshore-ui-init`), not by copying markup from these previews.

## Not synced
Components not shown: popovers and open states (Select list, DateRangePicker), SlideOver, ModalDialog, charts (BarChart, TrendLine, StackedBar, Sparkline), AppShell. Previews are closed, static states. Fonts: only the Latin subset of Geist and Geist Mono is carried (the package ships Cyrillic and Vietnamese subsets too). Tokens not carried: layout sizes, gaps, easing curves, the demo border, `transparent` values and the deprecated `--sherpa-*` aliases. Text styles carry size and weight only: the source defines no line heights.
