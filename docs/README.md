# Docs

These documents were written while the design system lived inside the Sherpa Discovery repository. They are kept for the reasoning and decisions behind it.

- **Current:** `design-system.md` (tokens, components, patterns), `quality.md` (what the checks cover), `package.md` (how the package is built and installed), `libraries.md` (why each dependency), `charts.md`, `tables.md`, `claude-design-system.md` (the generated mirror for Claude's Design System artifact).
- **History:** `bakeoff-report.md`, `chart-spike.md`, `design-system-scope.md` (earlier experiments and scope; the choices they led to are in the current documents).
- Mentions of Sherpa Discovery, customer names or "install a tarball" describe the situation before the split. Since 0.2.0 the system is its own repository, product-neutral, installed from GitHub Packages (see the root README and CHANGELOG).
